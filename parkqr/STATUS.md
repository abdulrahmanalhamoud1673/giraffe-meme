# يا نشمي: وين وصلنا (آخر تحديث: 2026-11-08، بعد شغل الليل)

## شغّال ومجرّب عندك
- **الموقع:** https://yanashmi.pages.dev (الصفحة الرئيسية، التسجيل، رمز QR، صفحة المسح، صندوق الرسائل بشكل شات).
- **الرحلة كاملة:** تسجيل ← رمز ← مسح من جهاز ثاني ← رسالة ← رد ← يظهر للمرسل.
- **التنبيهات:** وصلت على أندرويد (بدون صوت قبل التعديلات؛ ما اختبرنا بعدها).
- **الملفات المطبوعة:** `parkqr/print/` (بوستر A4 + 8 كروت). الرمز فيها يشير لـ `https://yanashmi.com/register`.

## مش مؤكد / ناقص
1. **الدومين `yanashmi.com`:** مضاف بـ Pages وحالته Active، بس آخر مرة فتحته طلع `DNS_PROBE_FINISHED_NXDOMAIN` (قبلها طلع 522). السبب مش معروف. **لا تطبع قبل ما يفتح.**
   - فحص 1: https://dnschecker.org/#A/yanashmi.com (هل الدومين موجود عالمياً؟)
   - فحص 2: افتح الموقع ببيانات الموبايل (مش الواي فاي).
   - فحص 3: Cloudflare ← Domain Registration ← Manage Domains: شوف حالة الدومين، وإذا في إيميل تأكيد ملكية (ICANN) لسا ما انضغط. هو مهم.
   - فحص 4: Cloudflare ← yanashmi.com ← DNS: لازم CNAME `@` يشير لـ `yanashmi.pages.dev` (Proxied).
2. **إشعارات الآيفون:** ما اتجربت بجهاز حقيقي.
3. **صوت الإشعار:** الموبايل بيقرر (إعدادات الموقع بالأندرويد + عدم الإزعاج). الصفحة المفتوحة بترن، وفي شرح بالصندوق.
4. **التحقق من الرقم (OTP):** مش موجود. الاسم والرقم بيتفحصوا شكلياً بس. لازم OTP قبل ما نرسل أي رسالة واتساب أو SMS لأرقام.

## اللي انعمل بعد ما نمت (شغل الليل)
- **لوحة الأرقام** `/results.html` (بمفتاح `ADMIN_KEY`): كم سجّل، كم فعّل التنبيهات، كم رسالة وصلت، نسبة الرد، متوسط وقت الرد، التسجيل اليومي. أعداد بس، بدون أسماء ولا أرقام هواتف. بالإضافة لنتائج الاستبيان.
- **معاينة المشاركة:** صورة `og.png` (واتساب وغيره) + أيقونة المتصفح. الرابط فيها `https://yanashmi.com`، فما بتظهر إلا لما الدومين يشتغل.
- **صفحة 404** بنفس الهوية، و`robots.txt`، وترويسات أمان (`_headers`)، وملف التنبيهات `sw.js` بدون كاش.
- **اسم حقيقي ورقم معقول:** حقلين (أول + عائلة)، حروف فقط، بدون أسماء تجريبية. رقم أردني بدون أنماط مزيفة، و3 سيارات كحد أقصى للرقم.
- **الاختبارات انتقلت للمستودع** `parkqr/tests/` (194 اختبار وحدة + 5 سيناريوهات متصفح). التشغيل: `cd parkqr/tests && npm install && npm test`.
- **ما عملته عمداً:** ما بدّلت المفاتيح السرية (بتخرّب التنبيهات اللي فعّلتها)، وما حطيت سياسة CSP (ممكن تكسر الموقع وما قدرت أجربها على Cloudflare). كلاهم بنعملهم وأنت صاحي.

## أفكار أخذناها من المنتجات المنافسة (2026-11-10)
المصدر: نتائج بحث (دعاية الشركات، ما قدرت أقرأ صفحاتهم). المنافسين: CarCall وNGF132 وParky (الهند)، Linko (باكستان)، Pingtag وHiddenContact وPlatenger وParkedChat (أوروبا وغيرها)، QR Guard، وتطبيق ملصق (Molsak) بالعربي. ما لقيت شي خاص بالأردن، بس ما دورت بمتاجر التطبيقات الأردنية.
- **اللي عندنا أصلاً:** صفحة بدون تطبيق، سبب جاهز مع إشعار، المرسل مجهول، حدود ضد الإزعاج.
- **اللي أضفناه:** زر "ذكّره" (مرة وحدة بعد 3 دقائق، بدون تغيير بقاعدة البيانات: التذكير بينخزن كصف kind=`nudge:<id>`)، متوسط وقت رد صاحب السيارة بصفحة المسح (بعد 3 ردود)، إشعار "عاجل" واهتزاز أطول لرسائل "ضربة" و"مستعجل"، زر دعوة الجيران بواتساب.
- **اللي ما أضفناه عمداً:** مكالمة أو واتساب مخفي (CarCall وHonkQR): مكلف وبدو مزود. التحقق بالكاميرا ضد الإنذارات الكاذبة (QR Guard): معقد، وما في إنذارات كاذبة لسا.
- **أغلب المنافسين بيبيعوا الستيكر دفعة وحدة بدون اشتراك**، وبعضهم بيشتغل مع شركات بستيكر بشعارها. هاد بيدعم خطتنا (ستيكر أولاً، شركات بعدين، اشتراك أخيراً).
