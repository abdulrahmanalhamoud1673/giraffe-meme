# استبيان "يا نشمي" (للنسخ إلى Google Forms)

العنوان: يا نشمي — ستيكر ينبّه صاحب السيارة المسكَّر عليها (دقيقتين)
الوصف: فكرة جديدة بالأردن. ما بنجمع بيانات شخصية إلا إذا أنت اخترت.

1. عمرك؟ (أقل من 25 / 25-34 / 35-44 / 45+) — اختيار
2. وين ساكن؟ (عمّان / إربد / الزرقاء / غيرها) — اختيار
3. معك سيارة؟ (نعم / لا) — اختيار
4. كم مرة مسكّر عليك أحد أو مسكّرت على أحد؟ (أسبوعياً / شهرياً / نادراً / ولا مرة) — اختيار
5. إيش بتعمل عادة؟ (أزمّر / أسأل بالمحل أو العمارة / أترك ورقة / أنتظر / غير ذلك) — اختيار
6. لو في ستيكر QR يمسحه الشخص ويبعتلك رسالة جاهزة بدون ما يعرف رقمك، تستخدمه؟ (أكيد / غالباً / ممكن / لا) — اختيار
7. كم مستعد تدفع للستيكر؟ (ما بدفع / 1-2 دينار / 3-5 / أكثر من 5) — اختيار
8. كم مستعد تدفع سنوياً للإشعارات؟ (ما بدفع / 3-5 / 5-10 / أكثر) — اختيار
9. أكثر شي بيقلقك؟ (خصوصية الرقم / الإزعاج / الناس ما رح تستخدمه / غير ذلك) — اختيار
10. لتجربة ستيكرات مجانية: واتساب أو إيميل (اختياري) — نص قصير

قرار: أكثر من 40% "أكيد/غالباً" بالسؤال 6 → نكمل مباشرة.
