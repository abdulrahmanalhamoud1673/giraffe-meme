# الأمان (يا نشمي)

## اللي مبني بالكود
- كل استعلامات قاعدة البيانات محضّرة (ما في حقن SQL).
- مفتاح صاحب السيارة عشوائي 28 حرف، والموقع ما بيخزّن غير الحساب نفسه.
- صفحة النتائج مسكّرة بدون مفتاح قوي (20 حرف فما فوق) وبترفض أي مفتاح انكشف، والمقارنة بزمن ثابت.
- حدود: 5 تسجيلات/يوم للجهاز، و300 تسجيل/ساعة للموقع كله، 3 سيارات للرقم، رسالة كل 5 دقائق للجهاز، 20 رسالة/يوم للسيارة، 300 استبيان/ساعة، 5 أجهزة إشعارات.
- حجم الطلب محدود (4 KB، والصورة 420 KB).
- الصورة: لازم من الكاميرا مباشرة، JPEG حقيقي، حد 220 KB، وبتنحذف بعد 7 أيام، ومش بتنعرض إلا لصاحب السيارة (مع CSP صارم).
- ملاحظة اللي بيمسح: فلتر شتائم ومعاكسة وأرقام وروابط. حظر المرسل من الصندوق.
- حذف الحساب بنفسه (صفحة delete-account + زر بالصندوق): يحذف كل شي. مطلوب من جوجل بلاي.
- سياسة أمان المتصفح (CSP) + HSTS + منع التضمين (frame) + nosniff + Referrer + Permissions.
- الإشعارات: بس لسيرفرات جوجل/آبل/موزيلا/مايكروسوفت.

## اللي بدك تعمله إنت بكلاودفلير (ما بقدر أعمله عنك)
1. غيّر `ADMIN_KEY` و`SALT` و`VAPID_PRIVATE` (انكشفوا بالمحادثة). الموقع بيرفض ADMIN_KEY القديم أصلاً.
2. فعّل التحقق بخطوتين على كلاودفلير وجيت هب وفيسبوك وجوجل.
3. خلي مستودع جيت هب Private، وفعّل حماية الفرع الرئيسي.
4. Cloudflare ← Security ← **Bot Fight Mode**: شغّله.
5. Cloudflare ← Security ← WAF ← **Rate limiting rules**: قاعدة على المسار `/api/*` (مثلاً 60 طلب بالدقيقة للـIP). المجانية بتسمح بقاعدة.
6. D1 فيها نسخ احتياطية تلقائية (Time Travel 30 يوم). تأكد إنها شغّالة.
7. لا تحط أي مفتاح بمحادثة أو صورة.

## بعد ما يصير فيه آلاف المستخدمين
- حاجز Turnstile (كابتشا مجانية) على التسجيل.
- مراقبة: تنبيهات كلاودفلير على الأخطاء.
- فحص الصور بالذكاء الاصطناعي (Workers AI) مربوط ومجرّب.
- مراجعة أمنية خارجية قبل الإعلان الكبير.
