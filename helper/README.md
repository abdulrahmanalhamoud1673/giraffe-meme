# 🏠 تواصل البيت (للشغالة البديلة)

صفحة بسيطة لما تيجي شغالة بديلة: بتفتح الرابط (أو بتمسح QR) وبتدوس على زر، والرسالة بتوصل **لكل العيلة** كإشعار على الموبايل.

- `index.html` ← صفحة الشغالة (أزرار كبيرة: وصلت / خلّصت / محتاجة مساعدة / رسالة / اتصلي).
- `setup.html` ← صفحة الإعداد للعيلة: بتولّد الرابط والـQR وبتجرب إرسال رسالة.

## ليش لكل العيلة مش لشخص واحد؟
أي حدا فاضي بيرد، ولا ينعلق الموضوع إذا أمك مشغولة. وطلبات "المساعدة" بتطلع بأولوية عاجلة.

## كيف بيشتغل
بدون سيرفر وبدون أسرار بالكود: الصفحة بتبعت الرسالة لـ [ntfy.sh](https://ntfy.sh) (مجاني)، واسم الموضوع (عشوائي وطويل) موجود **بالرابط بعد `#`** مش بالريبو. العيلة بتشترك بنفس الموضوع بتطبيق ntfy.

الخطوات: افتح `setup.html` ← انسخ الرابط للشغالة ← اشترك بتطبيق ntfy بالموضوع اللي ظاهر.
> ⚠️ أي حدا بيعرف الرابط بيقدر يبعت للموضوع. لا تنشره عام. إذا انسرّب، افتح `setup.html` بمتصفح جديد (بيولّد موضوع جديد).
