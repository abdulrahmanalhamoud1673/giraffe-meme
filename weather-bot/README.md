# بوت طقس الرابية 🌦👔

بوت تيليغرام بيبعتلك كل صبح طقس منطقتك (الرابية - عمان) وشو تلبس.
بيجيب التوقعات بالساعة من [Open-Meteo](https://open-meteo.com) (مجاني، بدون مفتاح)، وبيحسب اللبس من
الحرارة **المحسوسة** مش بس الحرارة، ومن المطر والهوا والشمس والغبار.

## التشغيل (5 دقايق)

1. **سوّي البوت**: افتح تيليغرام وكلّم [@BotFather](https://t.me/BotFather) ← `/newbot` ← خد الـ **token**.
2. **جيب الـ chat id**: ابعت أي رسالة للبوت اللي سويته، وبعدين افتح بالمتصفح
   `https://api.telegram.org/bot<TOKEN>/getUpdates` ودوّر على `"chat":{"id": ...}`.
3. **حط الأسرار بـ GitHub**: Settings ← Secrets and variables ← Actions:
   - Secrets: `TELEGRAM_BOT_TOKEN`, `TELEGRAM_CHAT_ID`
   - Variables (اختياري): `LAT`, `LON`, `PLACE_NAME`
4. جرّبه: Actions ← **Weather bot** ← Run workflow. بعدها بيشتغل لحاله كل يوم الساعة 6:30 صباحاً.

> ⚠️ الـ workflow بيشتغل من الـ default branch بس، فلازم تدمج هاد الفرع (merge) عشان الجدولة تبدأ.

## الدقة

- الإحداثيات الافتراضية تقريبية للرابية. **للدقة الأعلى** افتح Google Maps، كبس يمين على بيتك، وانسخ الرقمين
  وحطهم بـ `LAT` و`LON`.
- Open-Meteo بيدمج أفضل النماذج الجوية للمنطقة، ودقة الشبكة بحدود كم كيلومتر، يعني فرق شارع عن شارع ما
  بيبين، بس الطقس العام (مطر/حرارة/هوا) دقيق كفاية.

## تجربة محلية

```bash
cd weather-bot
python weather_bot.py --dry-run          # يطبع الرسالة بدون إرسال (بدها إنترنت)
python -m unittest                       # الاختبارات
```

## تعديل منطق اللبس

كله بدالة `outfit_advice` بملف `weather_bot.py`: العتبات (مثلاً 12° أو 30°) سهل تغيرها حسب إنك بتحس بالبرد
أو الحر أكتر من غيرك.
